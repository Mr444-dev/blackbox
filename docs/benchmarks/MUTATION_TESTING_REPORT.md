## 🔬 How Mutation Testing Works in BLACKBOX

Stryker.NET parses the Roslyn Syntax Tree of `Blackbox.Core` and introduces subtle, syntactically valid defects ("mutants"). If the unit test suite fails when a mutant is injected, the mutant is **KILLED** (Good). If the test suite continues to pass with the defective logic, the mutant **SURVIVED** (Bad / Gap in assertions).

### Example 1: Boundary Mutation (`>` vs `>=`)
- **Original Source Code**:
  ```csharp
  if (quantity <= 0)
      throw new WorkflowInvariantException("InvalidQuantity", "Reservation quantity must be strictly greater than zero.");
  ```
- **Injected Mutant**:
  ```csharp
  if (quantity < 0) // Allows 0 to slip through!
  ```
- **Result**: **KILLED** by `ResourceCapacityTests.Reserve_WhenQuantityIsZeroOrNegative_ThrowsInvariantException`.

---

### Example 2: Terminal State Guard Mutation
- **Original Source Code**:
  ```csharp
  public static bool IsTerminalState(WorkflowStatus status) =>
      status is WorkflowStatus.Completed 
             or WorkflowStatus.Failed 
             or WorkflowStatus.Cancelled 
             or WorkflowStatus.Compensated;
  ```
- **Injected Mutant**:
  ```csharp
  public static bool IsTerminalState(WorkflowStatus status) =>
      status is not WorkflowStatus.Completed; // Inverted condition
  ```
- **Result**: **KILLED** by `WorkflowStateMachineTests.TerminalState_ThrowsInvariantException_OnSubsequentTransitions`.

---

### Example 3: Resource Capacity Conservation Equation
- **Original Source Code**:
  ```csharp
  public int TotalCapacity => AvailableQuantity + AllocatedQuantity + ConsumedQuantity;
  ```
- **Injected Mutant**:
  ```csharp
  public int TotalCapacity => AvailableQuantity - AllocatedQuantity + ConsumedQuantity;
  ```
- **Result**: **KILLED** by `PropertyBasedWorkflowTests.PropertyBased_FuzzSequence_PreservesAllFormalInvariantsUnderRandomizedOperations`.
